# Study Tracker

競技プログラミング学習の内容を記録し、復習状況を管理するWebアプリです。

## 作成した背景

学習した内容が複数のメモに分散し、
復習が必要な内容を把握しづらかったため作成しました。

## 主な機能

- 学習記録の登録
- 学習記録の一覧表示
- 学習記録の編集
- 学習記録の削除
- タグの設定
- ステータス管理

## 使用技術

### フロントエンド

- React
- JavaScript

### バックエンド

- Node.js
- Express
- MongoDB
- Mongoose
